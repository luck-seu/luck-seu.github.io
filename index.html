What we explore

主要研究方向

从数据到知识、从系统到智能——四个方向紧密协作，共同推进泛在知识智能研究

01
Agent

数据智能体

研究检索增强生成（RAG）、大模型路由与定价、工具调用与记忆管理技术，打造能在真实知识环境中可靠工作的 Data Agent，实现从自然语言到结构化洞察的智能桥梁。

相关成果

  • Pricing Online LLM Services with Stackelberg Routing Game AAAI 2026
  • Memory-Augmented Data Agent with RAG In Progress
  • Multi-source Knowledge Conflict Resolution for LLM Agents Project
02
BigData

大数据处理平台

面向 PB 级数据的计算、存储与调度优化。研究大规模图数据处理、CPU-GPU 异构加速与分布式清洗系统，让复杂数据任务更快、更稳、更易用。

相关成果

  • MiniClean: A Single-Machine System for Cleaning Big Graphs SIGMOD 2025
  • Efficient Urban-Scale Traffic Data Generation BESC 2024 Best Paper
  • CPU-GPU Heterogeneous Pipeline for Graph Processing Project
03

城市计算

用时空数据理解城市运行。研究区域表征学习、交通流预测、轨迹建模、城市事件预测与社交网络分析，让数据驱动城市更高效地运转。

相关成果

  • Urban Region Pre-training and Prompting: A Graph Approach KDD 2025
  • Frequency-Conditioned Spatial Dynamics for Long-Term ST Forecasting KDD 2026
  • Event-Centric Framework for Crime Hotspot Prediction TKDE 2025
  • Integrating Heterogeneous Spatio-Temporal Interactions TKDD 2026
04

知识图谱

把多源异构城市信息组织成可查询、可推理的知识网络。研究知识抽取、实体对齐、关系推理与多模态语义融合，支撑数据治理与智能问答。

相关成果

  • IM-POI: Bridging ID and Multi-modal Representations ACM MM 2025
  • CasUGC: Aligning User-Generated Comment Evolution with Cascade Dynamics IJCAI 2026
  • Multi-source Urban Data Integration via Entity Linking EMNLP 2025
